# STOK REAL
Versi awal aplikasi pengecekan stok offline-first.

Import mendukung file iReap dengan kolom Item Code, Item Name, Category, Quantity, Min Stock, UoM, Cost @ IDR, Value IDR.

## Manual build APK
Upload project ini ke repository `medivet1437/stok-real`, commit ke `main`, buka Actions > Build APK > Run workflow. Setelah selesai, unduh artifact `stok-real-debug-apk`.
