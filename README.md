# STOK REAL — Final

Aplikasi Android pengecekan stok bertahap dengan import iReap harian.

Fitur utama: master barang, import iReap dengan Item Code unik, histori snapshot import, pemeriksaan bertahap, snapshot stok sistem per pemeriksaan, multi-foto kamera/galeri, tanda tangan pemeriksa dan penjaga toko, approval & lock, koreksi sebagai transaksi baru, riwayat, laporan PDF/XLSX/CSV, share, backup/restore satu file.

Build APK melalui GitHub Actions: Actions → Build APK → Run workflow → artifact `stok-real-debug-apk`.
